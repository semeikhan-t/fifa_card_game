   замени YOUR_API_KEY_HERE на ключ который я скажу отдельно
4. Удали ВСЕ файлы из папок:

ЗАДАЧА 3 — ПОЛНОСТЬЮ ПЕРЕСОЗДАТЬ БАЗУ ДАННЫХ
═══════════════════════════════════════════════

Удали старые init.sql и seed.sql и создай новые.

── init.sql ──────────────────────────────────

DROP TABLE IF EXISTS matches CASCADE;
DROP TABLE IF EXISTS players CASCADE;
DROP TABLE IF EXISTS countries CASCADE;

CREATE TABLE countries (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL,
    code        VARCHAR(20)  NOT NULL,
    ovr_attack  INT NOT NULL,
    ovr_defense INT NOT NULL
);

CREATE TABLE players (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL,
    country_id  INT REFERENCES countries(id),
    position    VARCHAR(5)   NOT NULL CHECK (position IN ('GK','DEF','MID','FWD')),
    overall     INT          NOT NULL CHECK (overall BETWEEN 0 AND 99),
    is_starter  BOOLEAN      NOT NULL DEFAULT true,
    photo_path  VARCHAR(255)
);

CREATE TABLE matches (
    id          SERIAL PRIMARY KEY,
    home_id     INT REFERENCES countries(id),
    away_id     INT REFERENCES countries(id),
    home_score  INT NOT NULL,
    away_score  INT NOT NULL,
    played_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

── seed.sql ──────────────────────────────────

Заполни seed.sql реальными данными для всех 15 сборных.
Для каждой сборной: 11 стартовых (is_starter=true) + 4 запасных (is_starter=false).
Позиции стартового состава: 1 GK, 4 DEF, 4 MID, 2 FWD.

Используй ТОЧНО эти country code для photo_path игроков:
kazakhstan, argentina, brazil, france, germany,
spain, england, portugal, usa, morocco,
netherlands, senegal, mexico, australia, south_korea
